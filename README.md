# 🎮 Квест по программированию (6–11 классы)

Интерактивный сайт для изучения Python через уровни-задачи с объяснением ошибок.

## 🚀 Быстрый старт

```bash
# 1. Установить зависимости
npm install

# 2. Запустить бэкенд (в одном терминале)
npm run server

# 3. В другом терминале — фронтенд
npm run dev
```

Или одной командой:

```bash
npm start
```

Открой http://localhost:5173

## 📁 Структура

- `src/levels/` — банк задач по классам
- `src/Level.jsx` — экран решения задачи
- `src/ErrorPanel.jsx` — красивый вывод ошибок
- `server/errorAnalyzer.js` — перевод ошибок Python на русский

## 🔒 Безопасность

Код ученика выполняется через публичный API **Piston** (emkc.org),
в изолированном Docker-контейнере. Для продакшена рекомендуется
поднять свой Piston.
